> **An end-to-end delivery analytics system analyzing 9,800+ Zepto orders to predict delivery delays using Random Forest ML model.**

---

## 📌 Project Overview

Analyzed Zepto's delivery performance data to identify operational bottlenecks and built a predictive model to forecast delivery delays.

---

## 🎯 Key Results

| Metric | Value |
|---|---|
| Total Orders Analyzed | 9,800 |
| Overall Delay Rate | 43.8% |
| Avg Delivery Time | 19 minutes |
| ML Model Accuracy | 100% |
| Top Delay Factor | Delivery Time Minutes |

---

## 🛠️ Tech Stack

| Layer | Tools |
|---|---|
| Data Processing | Python, Pandas, NumPy |
| Machine Learning | Scikit-learn, Random Forest |
| Visualization | Matplotlib, Seaborn |
| Notebook | Google Colab |

---

## 🔍 Key Insights

- **43.8%** of all orders are delayed
- **West region** has highest delay rate (44.3%)
- **Delivery Time** is the #1 factor causing delays
- Corporate customers face slightly higher delays than consumers
